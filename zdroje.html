Zdroje a citace AI

Přehled toho, odkud pocházejí informace na webu a jak mi při tvorbě pomohla umělá inteligence.

Použité externí zdroje

  • Liverpoolfc.com — Honours Oficiální web klubu, přehled zisků trofejí.
  • Wikipedie — Liverpool FC Historie klubu, milníky a jména legend.
  • Premier League — kluby Údaje o stadionu a soutěži.
  • MDN Web Docs — CSS Dokumentace k CSS Gridu a proměnným, které web používá.
  • Google Fonts — Inter Písmo použité na celém webu.

Citace použité AI

Při tvorbě webu jsem použil Claude (Anthropic). Kód jsem si nechal generovat po částech, vždy jsem ho zkontroloval, upravil texty a po každém kroku udělal commit do repozitáře. Obrázky nejsou stažené z internetu — jsou to vlastní SVG ilustrace vygenerované jako kód.

Prompty

„Chci moderní tmavý web o Liverpool FC. Napiš mi kompletní index.html a k tomu odpovídající externí style.css.“

„Přidej podstránku historie.html s časovou osou klíčových let a tabulkou trofejí. Použij stejné menu a stejný styl jako na hlavní stránce.“

„Vytvoř galerii se třemi obrázky a popisky. Obrázky mi vygeneruj jako vlastní SVG, ať neřeším autorská práva k fotkám.“

„Uprav CSS tak, aby se web dobře zobrazoval i na mobilu — přidej media query pro šířku do 760 px.“

„Navrhni mi rozdělení práce do deseti smysluplných commitů a napiš ke každému commit message.“

Poznámka k obrázkům

Znak klubu ani fotografie hráčů na webu schválně nepoužívám — jsou chráněné autorským právem a ochrannou známkou. Všechny ilustrace v galerii jsou původní.
