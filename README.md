# Liverpool FC

> Greatest club in the world.



## Obsah webu

| Soubor | Popis |
|---|---|
| `index.html` | Hlavní stránka — úvod, statistiky, přehled |
| `historie.html` | Časová osa klubu, tabulka trofejí, legendy |
| `galerie.html` | Galerie tematických obrázků s popisky |
| `zdroje.html` | Externí zdroje a citace použité AI |
| `style.css` | Jednotný tmavý design pro všechny stránky |
| `img/` | Vlastní SVG ilustrace |

## Použité technologie

- HTML5
- CSS3 (CSS proměnné, Grid, Flexbox)
- SVG grafika
- Google Fonts — Inter
- GitHub Pages pro publikaci

## AI

Web vznikl s pomocí AI modelu **Claude (Anthropic)**. Kompletní seznam
promptů a zdrojů je na stránce `zdroje.html`.
